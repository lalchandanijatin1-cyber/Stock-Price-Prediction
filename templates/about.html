ABOUT THE PROJECT

01 — PROJECT OVERVIEW

About StockPredict

StockPredict is an educational machine learning project that explores how historical financial market data can be processed and used with regression algorithms to estimate closing prices.

The project contains trained models for five different assets — Gold, Apple, Microsoft, NVIDIA and Amazon. Multiple regression algorithms were trained and evaluated before selecting the best-performing model for each asset.

02 — TECHNOLOGIES

Technologies & Models Used

The project combines web development, Python programming and machine learning to create a complete interactive prediction application.

Programming & Web Technologies

  • Python — Machine learning, data processing and Flask backend.
  • HTML — Structure of the web pages.
  • CSS — Styling, layout, animations and responsive design.
  • JavaScript — Client-side interactions and dynamic visual effects.
  • Jinja2 — Connecting Flask backend data with HTML templates.

Machine Learning & Data Tools

  • NumPy — Numerical operations and array processing.
  • Pandas — Data loading, cleaning and analysis.
  • Scikit-learn — Machine learning algorithms, preprocessing and evaluation.
  • Matplotlib — Data visualization.
  • Seaborn — Statistical data visualization.
  • Joblib — Saving and loading trained machine learning models.
  • Flask — Python web framework connecting the machine learning models with the website.

Machine Learning Models

  • 01
    Linear Regression

    A basic regression model used to learn the relationship between input features and closing price.

  • 02
    Lasso Regression

    Linear regression with L1 regularization to help control unnecessary feature influence.

  • 03
    Ridge Regression

    Linear regression with L2 regularization. Ridge achieved the strongest evaluation results across the five assets in this project.

  • 04
    Support Vector Regression

    A support-vector-based regression algorithm used to compare a different approach to the prediction problem.

04 — PROJECT CONNECTIONS

How The Project Connects

FRONTEND

HTML + CSS + JavaScript

Provides the interface through which users interact with the prediction system.

BACKEND

Flask + Python

Receives requests, processes inputs and communicates with the trained models.

MACHINE LEARNING

Scikit-learn Models

Trained regression algorithms generate the predicted closing price.

MODEL STORAGE

Joblib + .pkl

Trained models are saved and loaded by the Flask application.

DATA

Historical Market Data

Historical trading information is used during model training and evaluation.

TEMPLATES

Flask + Jinja2

Backend values can be passed into the HTML templates and displayed dynamically.
