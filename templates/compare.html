02 — PRIMARY METRIC

Why Did We Use R² Score?

R² — Coefficient of Determination

R² Score was selected as the primary metric for comparing the models because it indicates how well the model explains the variation in the target variable.

In this project, the target variable is the Close price. A higher R² value means that the model explains more of the variation in the closing-price data used for evaluation.

Closer to 1 Better explanatory performance
Closer to 0 Weak explanatory performance
Below 0 Can indicate very poor performance

Therefore, when comparing models trained and evaluated on the same asset and dataset, we primarily considered the model with the higher R² Score.

R² is used as the primary selection criterion, but MSE and RMSE are also shown because they provide information about the actual magnitude of prediction errors.

03 — SELECTED MODEL

Why Was Ridge Regression Selected?

After comparing Linear Regression, Lasso Regression, Ridge Regression and Support Vector Regression across all five assets, Ridge Regression produced the strongest overall results in this project.

Ridge achieved the highest R² Score for Apple, Gold, Microsoft, NVIDIA and Amazon when comparing the four models for each asset.

Ridge also produced very low MSE and RMSE values for these assets, indicating relatively small prediction errors on the evaluation data.

Overall Selection

Ridge Regression was selected as the preferred model for this project based on its evaluation performance across the five assets.

This selection only describes performance on the data used for evaluation. It does not mean Ridge Regression can reliably predict future stock prices.

06 — UNDERSTANDING THE METRICS

What Do These Metrics Mean?

MSE

Mean Squared Error

MSE calculates the average squared difference between the actual and predicted values.

Lower is better
RMSE

Root Mean Squared Error

RMSE is the square root of MSE and represents prediction error in the same unit as the target variable.

Lower is better
R²

R² Score

R² indicates how much of the variation in the target variable is explained by the model.

Higher is better
